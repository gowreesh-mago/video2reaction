# Code and hypothesis review: VAD to DINO

## Does the code test the hypothesis?

Yes, for a specific question: can the existing visually predicted three-dimensional scene coordinates reconstruct DINO features on held-out clips, and are those reconstructions useful to the frozen DINO reaction head? Every decoder receives predicted VAD, not ground-truth emotion distributions. Training/validation split hashes, feature hashes, sample IDs, and source checkpoints are verified.

## Adversarial checks

- **Label leakage:** Test reaction labels are opened only after decoder choices are saved. The test VAD is generated by an already trained visual checkpoint. No label-derived VAD is used.
- **Selection bias:** All ridge strengths and radial-basis widths are selected by validation reconstruction error, not test KL. The overall preferred mapping is also chosen by mean validation error.
- **False similarity from a common mean:** Report a training-mean control, error reduction relative to that mean, and centered cosine. Raw cosine alone is insufficient.
- **Too many scenes from long clips:** Fit at most eight scenes per clip and assign equal total clip weight. Test reconstruction metrics also give each clip equal weight.
- **Whether pairing matters:** Shuffle complete sampled VAD trajectories between training clips; preserve their internal scene order. This provides a matched nonlinear control.
- **Whether three dimensions are intrinsically inadequate:** Compare with a train-fitted three-component DINO reconstruction and a 32-component reference. These controls do not make the VAD representation more informative.
- **Head-wiring mistake:** Preserve per-scene layer normalization and projection before mean pooling. Check original-feature predictions against the saved DINO baseline before scoring reconstructions.
- **Runtime/checkpoint drift:** Re-infer validation VAD and probability distributions and compare with saved arrays within float32 CPU/GPU tolerance. This is included in the three-video smoke test.
- **Unjustified rare-emotion claims:** The rare set is determined by training probability mass. Report target support, recall and predicted probability mass. Zero dominant-label support does not establish failure on a rare emotion.
- **False independence:** Test clips can share movies. Paired KL intervals bootstrap movies, while seed standard deviations remain a separate descriptive statistic.
- **False claim of a paper reproduction:** The original fine-tuned LLaVA/Qwen output is unavailable. Published aggregate numbers and our visual-description model are not substituted.

## What can the result establish?

Positive reconstruction beyond shuffled/mean controls would show visual information retained in these coordinates. Lower KL than the original VAD decoder would show a useful alternative way of decoding that representation with the saved DINO head. Matching original DINO would show that this bottleneck preserves enough information for that head.

A negative result rules out only these mappings and this learned VAD representation under the tested protocol. It cannot rule out a decoder trained with a new reaction head, jointly trained embeddings, other architectures, or the general psychological usefulness of valence/arousal/dominance. The reverse mapping cannot create information that was discarded. There are no scene-level VAD labels or comment timestamps to establish that a learned trajectory describes the audience at each moment.

## Implementation notes

Local regression tests check held-out linear/quadratic reconstruction, training-only standardization, deterministic radial-basis centers, equal clip weights, mean/perfect reconstruction controls, retrieval ties, and the existing probability/metric conventions. Production result JSON is written atomically in the latest source; the launched frozen source uses a complete-file end-of-run write and is independently checked before collection.
